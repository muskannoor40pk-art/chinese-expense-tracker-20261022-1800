## Overview
Expense Tracker (CN) is a minimalist, single-page web application designed for users who value privacy and simplicity. It allows you to log expenses, categorize them, and visualize your spending habits through a responsive dashboard—all directly within your browser. Since it uses `localStorage`, your data stays on your device, ensuring complete privacy.

## Features
*   **Categorized Tracking:** Easily label expenses (e.g., Food, Transport, Entertainment).
*   **Monthly Summaries:** View beautiful summary cards for your current monthly financial status.
*   **Visual Analytics:** Built-in pure CSS/JS bar chart to visualize spending patterns.
*   **Data Persistence:** Automatic saving via browser `localStorage`.
*   **Zero Dependencies:** Built with pure HTML, CSS, and Vanilla JavaScript.
*   **Lightweight:** Fast loading and works perfectly offline.

## Localization Notes
